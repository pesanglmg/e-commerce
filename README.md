## Overview

SecondCircuit lets anyone sign up and immediately start buying or selling second-hand electronics accessories. Every registered user can post listings and shop from others — no separate seller account needed. An admin panel provides full control over users, products, and orders.

This project was built to demonstrate:

- Full-stack JavaScript development (React + Node/Express)
- RESTful API design with JWT authentication
- MongoDB data modeling with Mongoose
- Reusable React component architecture
- Role-based access control (user vs. admin)
- Responsive, mobile-first UI with Tailwind CSS
